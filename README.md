### 4. Microsoft Forms - UC & Near Miss Reporting System

A mobile-friendly Microsoft Forms-based reporting system developed for **TBIF Foods Pvt. Ltd.** to record **Unsafe Conditions (UC)** and **Near Miss (NM)** observations.

The system provides a structured way for employees to submit safety observations from their mobile devices and maintain centralized records for further tracking and analysis.

#### Key Features

- Mobile-friendly reporting
- Company employee-only access
- Automatic email capture
- Section and shift details
- Safety observation details
- Safety classification
- Severity and probability assessment
- Responsible person tracking
- Observation status tracking
- Photo/Video evidence upload
- Automatic response storage in Excel
- SharePoint-based file storage
- Data can be used for safety dashboards and analysis

#### Form Sections

- Observation Details
- Reporter Information
- Safety Classification
- Corrective / Preventive Action
- Severity & Probability
- Responsible Person
- Observation Status
- Photo / Video Evidence

#### Technologies Used

- Microsoft Forms
- Microsoft Excel
- SharePoint
- Microsoft 365

#### Data Flow

Employee  
→ Microsoft Forms  
→ Form Response  
→ Microsoft Excel  
→ SharePoint File Storage  
→ Tracking / Analysis / Safety Dashboard
