# Power Apps - Manufacturing Operations Trackers

## Overview

This project demonstrates Power Apps applications developed for manufacturing and operational data tracking.

The applications are designed to replace repetitive manual Excel-based data entry and provide users with structured interfaces for updating and viewing operational information.

The portfolio includes three Power Apps solutions:

1. RM Tracker
2. MP Tracker
3. EGA Tracker

> **Note:** Screenshots and examples in this repository are sanitized for portfolio purposes and do not contain confidential company information.

---

# 1. RM Tracker

## Overview

The RM Tracker is a Power Apps application designed to support raw material tracking and daily operational updates.

The application provides users with an interface to update and check raw material information without relying entirely on manual Excel data entry.

## Key Features

- Raw material tracking
- Inward material updates
- Outward material updates
- Material information entry
- Centralized data tracking
- User-friendly data entry
- Operational data visibility

## Business Purpose

The application helps simplify daily raw material tracking by providing a structured interface for users to update and check material information.

# 3. EGA Tracker

## Overview

The EGA Tracker is a Power Apps application designed to track Excess Give Away (EGA) for finished-goods packets.

The application captures packet weight information and calculates EGA based on average/target weight and net packet weight.

## Key Features

- Date selection
- Shift selection
- Section selection
- Variant / SKU selection
- Average weight entry
- Net weight entry
- Difference calculation
- EGA % calculation
- Supervisor identification
- Date-wise EGA reporting
- Shift-wise filtering

## EGA Calculation

The application calculates EGA using the weight difference between the average/target weight and the measured net weight.
